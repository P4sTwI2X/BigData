21KHMT - Big Data

## Seminar summary

Students were tasked with investigating and learning about ML-based tools, ranging from modern data management and data pipelines such as Apache Kafka, and image generators such as Gemini, or Stable Diffusion, to data visualization tools such as Power BI.

We chose the topic about image generators, which we investigated and experimented with Imagen, Stable Diffusion and Midjourney.
