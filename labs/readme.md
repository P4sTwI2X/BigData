21KHMT - Big Data

### Labs summary

This Big Data course includes working with Apache Hadoop and Apache Spark for large-scale data management (storage, distribution, accessibility) and data retrieval requests.

Exercises include performing basic operations (boot up, GUI, exit, store, etc.) on a single-cluster, then perform simple problems using MapReduce (term frequency, filter, calculate TF-IDF) and data preprocessing problems (K-Means).

The exercises are divided into 3 labs.

### Lab 1: Introduction to Apache Hadoop

1. Installation of Apache Hadoop and set up a single-cluster HDFS.

2. Perform a simple problem of MapReduce.

### Lab 2: Document Clustering with Hadoop MapReduce

1. Application of MapReduce on common simple queries, such as TF-IDF, filtering, ranking, and K-Means.

### Lab 3: Spark Streaming (with Python)

1. Streaming simulation from static data.

2. Perform simple queries on a data stream, such as filtered counting, calculations and feature extraction.
